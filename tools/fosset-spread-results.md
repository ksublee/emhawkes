# Fosset 스프레드 모형 예제 검증

## 대상과 구현

Fosset, Bouchaud and Benzaquen (2020), *Endogenous Liquidity Crises*,
[DOI](https://doi.org/10.1088/1742-5468/ab7c64),
[공개원고](https://arxiv.org/pdf/1912.00359), 4.1절 식 (8a)–(8b)의 선형 모형을 구현했다.
모수는 정상 스프레드의 합성 예제를 위해 선택했다.

* 사건 1은 스프레드 확대, 사건 2는 축소다. 초기 스프레드는 1틱이다.
* 확대 강도는 `nu_plus + sum(a * b * exp(-b * age))`다. 커널의 적분값은 `a`, 사건 후 증가량은 `a * b`다.
* 축소 강도는 `nu_minus * (spread >= 2)`다. 1틱에서 정확히 0이 되며, 축소 이벤트는 excitation을 만들지 않는다.
* `mu`는 이전 행의 누적 횟수로 현재 스프레드를 구한다. 다음 baseline은 사건 직후 상태를 사용한다.
* 함수형 `alpha`의 다른 세 항은 고정 0이다. 같은 이름의 `log_b`가 `alpha`와 `beta`에서 공유되어 추정 모수는 네 개다.
* 양의 rate는 로그, `0 < a < 1`은 logit으로 추정한다. 초기 excitation은 명시적으로 0이다. 정상 스프레드는 추가로 `nu_plus / (1-a) < nu_minus`를 요구한다.

예제 함수는 `inst/examples/fosset-spread.R`에 두었다. 패키지 namespace에 새 함수를 export하지 않는다.
Extended vignette는 설치된 이 파일을 읽어 함수 정의부터 시뮬레이션·추정·복원까지 실행한다.
패키지의 우도·시뮬레이션·최적화 코드는 수정하지 않았다.

## 논문 수식과의 비교

초기 스프레드 1·3, `a = 0.2, 0.4, 0.7`, `b = 0.5, 2, 3`의 18개 조합을 R과 C++ 경로에서 비교했다.
기준 계산은 모든 과거 확대 이벤트를 직접 합산한다. 패키지의 성분 재귀나 적분 도우미를 사용하지 않는다.
사건별 구간 적분을 따로 계산해 유형별 잔차도 확인했다.

| 비교값 | 최대 절대 차이 |
| --- | ---: |
| 사건 직전 강도 | 4.44e-16 |
| 사건 직후 강도 | 4.44e-16 |
| 로그우도 | 1.78e-15 |
| 유형별 적분 잔차 | 2.22e-16 |

1틱에서 축소 이벤트를 관측한 잘못된 경로의 우도는 두 엔진 모두 `-Inf`다.
시뮬레이션의 최저 스프레드는 1틱이며, 1틱에서의 사건 전후 축소 강도는 정확히 0이다.
우도와 강도 복원이 시뮬레이션 후 난수 상태를 바꾸지 않는지도 검사했다.

## 추정

고정 seed `20261018`, 사건 4,000개로 네 모수를 모두 추정했다.
기본 수치미분과 stats BFGS를 사용했다. 표준오차는 최종 stable 곡률에 delta method를 적용한 원래 모수 척도다.

| 모수 | 참값 | 추정값 | 표준오차 |
| --- | ---: | ---: | ---: |
| nu_plus | 1.0000 | 0.981120 | 0.057767 |
| nu_minus | 3.0000 | 3.086500 | 0.069016 |
| a | 0.4000 | 0.424002 | 0.032804 |
| b | 2.0000 | 1.792073 | 0.226857 |

* 서로 다른 세 시작점에서 수렴 코드 0, 곡률 진단 `ok`를 얻었다. 최대 로그우도 차이는 4.36e-08다.
* 같은 시작점의 R과 자동 C++ 추정은 계수·로그우도·공분산이 일치했다. 자동 경로의 실제 엔진은 C++다.
* 확대 이벤트 시각만으로 계산한 별도 우도를 `stats::optim()`으로 최적화했다. 원래 모수 척도에서 패키지 추정과의 최대 차이는 2.63e-07다.
* 축소율의 독립 해 `축소 횟수 / 스프레드 개방 시간`은 3.086499925다. 패키지 추정은 3.086500023이다.
* `log(nu_minus)`의 정보량은 축소 횟수다. 조건부 추정에서 공분산이 그 역수와 일치했다.
* 별도 우도의 `optimHess()`로 네 모수의 표준오차를 확인했다. 패키지 stable 표준오차와 최대 상대 차이는 6.92e-06다.
* `fitted_hspec()`와 `fit_initial_state()`로 복원한 우도도 적합 우도와 일치했다.

시간은 단일 실행에서 자동 C++ 10.72초, R 38.66초였다. 이는 반복 성능 벤치마크가 아니며 환경에 따라 달라진다.

## 시뮬레이션과 반복 추정

4,000개 사건의 총 적분강도 증가량 평균은 0.97954이고, 조건부 사건 유형의 martingale 표준화 합은 -0.64589였다.
각각 단위 지수분포 평균 및 조건부 사건 확률과 양립하는지 사전에 정한 보수적 범위로 확인했다.

40,000개 사건에서 초기 2,000개 사건을 제외한 시간 가중 스프레드 개방 비율은 0.55133이다.
논문의 정상 상태 이론값 `nu_plus / (nu_minus * (1-a))`은 0.55556이다.
사건 시점의 단순 행 비율 대신 각 구간의 길이로 가중했다.

고정 seed 4101–4106에서 각각 사건 3,000개를 생성하고 같은 시작점으로 추정했다.
모든 실행이 수렴하고 곡률 진단 `ok`와 유한한 표준오차를 얻었다. 아래는 여섯 결과 전체의 요약이다.

| 모수 | 참값 | 추정 평균 | RMSE | 최소 | 최대 |
| --- | ---: | ---: | ---: | ---: | ---: |
| nu_plus | 1.00000 | 1.03858 | 0.05750 | 0.99647 | 1.11345 |
| nu_minus | 3.00000 | 3.03793 | 0.09996 | 2.85752 | 3.16822 |
| a | 0.40000 | 0.38725 | 0.03036 | 0.34449 | 0.43107 |
| b | 2.00000 | 2.13403 | 0.27903 | 1.82556 | 2.58024 |

이 작은 반복 실험은 구현 점검용이다. 표준오차의 일반적인 신뢰구간 포함률이나 전역 최대를 보장하지 않는다.
