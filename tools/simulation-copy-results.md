# 시뮬레이션 이력 복사 개선

## 변경

`hsim()`의 현재 사건 후 강도 성분과 반환할 전체 이력을 분리했다. `rarrival()`과 `darrival()`에는 현재의 작은 성분 행렬을 전달한다. 내부 도우미의 기존 이력 입력도 유지한다. 감쇠, 사건 유형 선택, 커널 열 갱신, 난수 호출 순서는 그대로다.

`mu`, `impact`, `rmark` 호출에는 우도 계산에서 쓰던 `prepare_component_call()`을 재사용한다. 요청한 인자만 평가하고 호출 전에 그 값을 고정한다. 선택하지 않은 큰 이력을 목록에 담지 않는다. 함수의 기본값과 `...`의 전체 문맥은 유지한다. 사용자가 인자를 보관하는 경우에도 호출 당시의 값을 읽는다. 출력 형식과 조기 종료 시의 행 자르기는 바꾸지 않았다.

시뮬레이션은 계속 R로 실행한다. 엔진 옵션과 추정 코드는 바꾸지 않았다.

## 정확성

수정 전 `90ead474d99b5bdb59f177a62e53da586a556589`와 수정본을 별도 소스와 라이브러리로 설치했다.

* 40개 비교에서 사건 시간·유형·마크·누적 횟수·강도 성분, 출력 속성, 경고 및 최종 `.Random.seed`가 `identical()`로 일치했다. 모형 객체 자체는 비교 대상에서 제외했다.
* 12개 대표 모형을 Mersenne-Twister와 L'Ecuyer-CMRG에서 비교했다. 비영 초기 횟수, 기본·스칼라·행렬 초기 강도, 이름 있는 커널, 0 baseline, 소멸, 같은/다른 감쇠율, signed 성분, gamma 잔차 생성, 초기 행만 있는 출력도 포함했다.
* 명시적 인자와 `...`를 받는 콜백이 인자를 나중에 읽도록 보관하는 경우, 호출 순서와 전체 문맥이 수정 전과 같았다. 기본 인자를 불필요하게 평가하지 않는지도 확인했다.
* 20개 모형·사건 수 조합의 반복 측정에서도 모든 출력 자료와 최종 난수 상태가 정확히 일치했다.
* 12개 모형의 1,000개 사건을 R과 C++ 우도로 각각 복원했다. 사건 전후 강도와 성분의 최대 상대 척도 오차는 0이었다. 누적 횟수는 독립 누적합과도 일치했다.

지속 회귀 검사는 `tests/simulation-dispatch.R`에 추가했다. 콜백별 갱신 시점과 보관된 문맥, 현재 상태 입력과 기존 이력 입력의 난수 계약, 초기 행과 소멸, 두 우도 엔진을 통한 강도 복원을 검사한다.

## 시간

Windows 11, R 4.6.0에서 측정했다. 각 조건은 새 R 프로세스에서 짧은 준비 실행 후 3회 측정했다. 아래는 전체 `hsim()` 호출의 경과 시간 중앙값이다. 설치·시작·출력 비교 시간은 제외했다. 수정 전후 실행 순서를 조건마다 바꿨고 다른 측정 작업을 동시에 실행하지 않았다.

사건 수 10,000개이며 초기 행은 별도다. 이전 진단용 함수가 아닌 공개 `hsim()`끼리 비교했다.

| 모형 | 수정 전 | 수정 후 | 배속 |
| --- | ---: | ---: | ---: |
| 단변량 (D=1, K=1) | 0.48초 | 0.31초 | 1.55배 |
| 다변량 (D=4, K=4) | 1.84초 | 0.35초 | 5.26배 |
| 다중 커널·같은 감쇠율 (D=4, K=8) | 3.21초 | 0.37초 | 8.68배 |
| 다중 커널·다른 감쇠율 (D=4, K=8) | 3.11초 | 0.40초 | 7.78배 |
| 마크·eta (D=4, K=8) | 8.89초 | 0.43초 | 20.67배 |
| 현재 강도 의존 impact (D=4, K=8) | 17.28초 | 0.41초 | 42.15배 |
| 현재 강도 의존 impact + ... (D=4, K=8) | 16.51초 | 0.41초 | 40.27배 |
| 사건 수·마크·현재 강도 (D=4, K=8) | 18.16초 | 0.55초 | 33.02배 |

3,000개 사건의 단변량은 두 버전 모두 0.11초였다. 모든 측정 조합에서 중앙값은 같거나 줄었다. 실행 환경과 메모리 할당·GC 상태에 따라 시간과 배속은 달라진다. 이전 프로파일링 수치와 섞지 않고 이번에 다시 설치한 두 버전만 비교했다.

이전 진단의 선택적 목록 생성과 달리 이번 구현은 기존 `forceAndCall()` 호출기를 재사용한다. 사용하지 않는 `...` 인자가 있는 모형도 이번 측정에서 개선됐다. 전체 이력을 실제로 보관하거나 처리하는 사용자 함수에는 여전히 그 비용이 발생할 수 있다.

## 재현

이 저장소 루트에서 수정 전후 소스를 별도 라이브러리에 설치한 뒤 실행한다. `WORK`에는 원시 경로와 로그를, `OUT`에는 작은 요약 파일을 저장한다. 전체 실행에는 느린 수정 전 경로도 포함된다.

```text
Rscript --vanilla tools/run-simulation-copy.R OLD_LIB NEW_LIB WORK OUT
```

[개별 시간](simulation-copy-results/timings.csv), [요약과 할당량](simulation-copy-results/summary.csv), [경계 조건 비교](simulation-copy-results/checks.csv), [강도 복원](simulation-copy-results/replay.csv), [실행 환경](simulation-copy-results/session-info.txt)을 함께 저장했다. 도구와 원시 측정값은 패키지 빌드에서 제외된다.
